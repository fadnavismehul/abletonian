# Code of Conduct

This project follows the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good faith, welcome newcomers (musicians who
have never opened a PR included), and keep criticism about the work.

Report unacceptable behaviour privately to the maintainers through a
[GitHub security advisory](https://github.com/fadnavismehul/abletonian/security/advisories/new)
(it is private to maintainers) or by contacting a maintainer directly.
Maintainers will review reports promptly and keep the reporter's identity
confidential.
